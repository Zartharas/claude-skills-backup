# Telemetry Onboarding

1. Define security use case before collection.
2. Identify authoritative source and export method.
3. Estimate event types, volume, burst, latency, retention.
4. Define source/category/index/table.
5. Define parsing and time semantics.
6. Define normalization target.
7. Define quality checks.
8. Define ownership and operational monitoring.
9. Pilot.
10. Validate end-to-end before scaling.
