# Detection Engineering

1. Define threat behavior.
2. Write hypothesis.
3. Identify required telemetry.
4. Prove telemetry is present and timely.
5. Normalize.
6. Build analytic.
7. Validate syntax.
8. Validate semantics against positive/negative cases.
9. Check false positives and null fields.
10. Check production-window behavior and performance.
11. Map ATT&CK if useful.
12. Define response/ownership.
13. Record limitations.
