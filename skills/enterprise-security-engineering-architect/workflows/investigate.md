# Investigate

1. Define time window and subject.
2. Establish source reliability and clock/timezone.
3. Build an event timeline from direct evidence.
4. Separate observed actions from interpretations.
5. Correlate identity, endpoint, network, cloud, SIEM, and response data only where keys/time support it.
6. Map relevant ATT&CK behavior when useful.
7. Identify gaps and alternative explanations.
8. State findings with confidence.
