# Normalization

1. Inspect representative raw events.
2. Identify semantic event class.
3. Determine target schema: CIM, ASIM, OCSF, or product-native.
4. Map required fields from evidence.
5. Preserve original/raw fields where appropriate.
6. Avoid fabricating values solely to satisfy schema.
7. Validate null/missing cases.
8. Validate high-volume and edge cases.
9. Validate downstream analytics/data models.
