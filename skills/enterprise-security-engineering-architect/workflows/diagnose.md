# Diagnose

1. State symptom and expected behavior.
2. Draw the end-to-end system path.
3. Mark what is already proven.
4. Choose the earliest unproven boundary.
5. Run/request one discriminating test.
6. Update hypotheses.
7. Continue only as far downstream as evidence allows.
8. Recommend the smallest evidenced fix.
9. Validate repaired boundary plus one downstream consumer.
10. Record owner/handoff if outside current control.
