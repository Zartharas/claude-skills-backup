# Integration Design

Capture:
- producer;
- consumer;
- API/syslog/stream/file mechanism;
- authentication;
- authorization/scopes;
- schema/version;
- rate/volume;
- batching;
- buffering;
- replay;
- ordering;
- latency;
- deduplication;
- retry/backoff;
- error handling;
- secret management;
- network path;
- data sensitivity;
- retention;
- observability;
- owner;
- acceptance test;
- rollback.

Prefer supported native integrations over brittle custom polling when requirements are equivalent.
