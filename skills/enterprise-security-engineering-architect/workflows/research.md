# Research

1. Define question and practical objective.
2. Search primary literature/standards/product sources.
3. Identify current state of practice.
4. Separate documented behavior, vendor claims, independent evidence, and hypotheses.
5. Identify gap/limitation.
6. Form a falsifiable hypothesis.
7. Design prototype/experiment.
8. Define baseline and metrics.
9. Test.
10. Compare.
11. State limitations.
12. Assess novelty only after broad current research.
