# Architecture Review

1. Define business/security objective.
2. Inventory major components and owners.
3. Trace control/data/telemetry flows.
4. Mark trust and administrative boundaries.
5. Identify single points of failure and bottlenecks.
6. Evaluate resilience, replay, recovery, and observability.
7. Evaluate identity/authorization.
8. Evaluate data sensitivity/retention.
9. Compare alternatives and tradeoffs.
10. Produce decision + assumptions + risks + validation plan.

Use Archify Web separately if a finished diagram artifact is requested.
