# Enterprise Security Engineering Architect v1.0.0

A ChatGPT-web skill for evidence-first L3/L4/L5 enterprise security engineering, architecture, troubleshooting, integration, detection engineering, and applied research.

## Designed for

- SIEM / SOAR
- EDR / XDR
- firewalls / network security
- proxies / SWG / SSE / ZTNA
- DLP / data security
- identity / MFA
- cloud security integrations
- vulnerability / exposure management
- threat intelligence
- security telemetry pipelines
- detection engineering
- cross-platform architecture and RCA

## Important boundary

This is the **enterprise platform/system engineering** skill.

It does not replace specialist skills for:
- AppSec source-code review
- software supply chain
- AI/RAG/MCP security
- cloud-native security architecture
- deep cryptography/PKI
- OT/ICS
- mobile app security
- diagram rendering
- AI watermark/provenance
