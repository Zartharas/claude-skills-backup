# Applied Security Research Method

1. Define the technical question.
2. Establish current architecture/state of practice.
3. Separate vendor claim from independent evidence.
4. Identify known limitation or research gap.
5. Formulate a falsifiable hypothesis.
6. Define architecture/prototype.
7. Define threat model.
8. Define experimental variables and controls.
9. Define measurable outcomes.
10. Test reproducibly.
11. Compare against baseline.
12. State limitations and alternative explanations.
13. Assess novelty only after current literature/product research.

Prefer primary papers, standards, official schemas, reproducible repositories, and current vendor documentation.

Do not claim novelty from absence in a small search.
