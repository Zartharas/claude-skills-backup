# Evidence matrix fields

| Field | Record |
| --- | --- |
| Element | Precise technical element being assessed |
| Source | Stable citation, identifier, version/date |
| Evidence | Exact supported disclosure or concise paraphrase |
| Relation | Explicit overlap, partial overlap, analogous, or unknown |
| Confidence | Evidence quality and remaining access/search limits |
| Next test | Search, experiment, or counsel question that could change it |

Never use a matrix row to assert novelty, patentability, validity, or freedom
to operate.
